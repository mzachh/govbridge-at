Data boundary

Local-first by design

The extension observes supported Meine SV pages in an isolated content script, keeps normalized claim data in extension storage, and registers proxy tools through document.modelContext in the page's MAIN world.

  1. 1Meine SV DOMread-only observation
  2. 2Chrome storagenormalized local state
  3. 3Content Bridgeclosed tool protocol
  4. 4WebMCPMAIN-world proxy tools

The four query tools use readOnlyHint: true and read stored observations. The search action is discoverable on the type/range and results pages, runs in the isolated page context, and clicks only the validated date-range form's Weiter control when present. Its acknowledgement does not confirm fresh results.

PoC boundary: OEGK page scripts can observe or race bridge traffic and invoke the bounded search action. Only normalized query results or search inputs/acknowledgements cross—never credentials, cookies, raw HTML, PDFs, or storage internals. This dashboard displays aggregate counts only. Stored observations may predate the current search.
