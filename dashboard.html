Data boundary

Local-first by design

The extension observes supported Meine SV pages in an isolated content script, keeps normalized claim data in extension storage, and registers proxy tools through document.modelContext in the page's MAIN world.

  1. 1Meine SV DOMread-only observation
  2. 2Chrome storagenormalized local state
  3. 3Content Bridgeclosed read-only RPC
  4. 4WebMCPMAIN-world proxy tools

PoC boundary: OEGK page scripts can observe or race MAIN-world bridge traffic. The bridge carries only one normalized, read-only tool result per invocation—never credentials, cookies, raw HTML, PDFs, or storage internals. This dashboard displays aggregate counts only.
